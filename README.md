# Riemann Zeta Prime Connection

This example demonstrates the fundamental connection between the Riemann Zeta function and prime numbers. It calculates an approximation of the Zeta function for a real input using both its infinite sum definition and the Euler product formula, highlighting their equivalence. This relationship is central to the Riemann Hypothesis, a key topic in the accompanying article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
